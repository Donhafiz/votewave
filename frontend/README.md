# VoteWave Frontend

Enterprise-grade election intelligence frontend.

## Features

- Real-time election streaming
- AI analytics
- Distributed operations center
- Live audit logs
- Event-driven architecture
- Socket.io integration
- Offline-ready PWA

## Run Locally

```bash
python -m http.server 3000
```

or

```bash
npx serve .
```

## Production

Deploy to:

- Vercel
- Netlify
- Cloudflare Pages

## Backend Requirements

Expected API:

- /api/auth
- /api/elections
- /api/votes
- /api/results
- /api/operations
- /api/analytics
- /api/ai
